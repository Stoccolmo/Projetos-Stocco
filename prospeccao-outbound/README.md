## Estrutura

- `docs/` — especificação original e handoff de continuidade (arquitetura, bugs corrigidos, convenções de edição).
- `decisoes/` — registro vivo de decisões e achados por sessão.
- `scripts/` — cópia mais recente do código-fonte publicado no Apps Script (`Codigo.gs` + `Index.html`). A fonte de verdade é sempre o projeto Apps Script; esta cópia é só espelho.
